DNET STUDIO — WHATSAPP WEBSITE
=================================

Location: D:\DNET-Studio-WhatsApp
Main page: index.html
Launch shortcut: OPEN WEBSITE.bat

HOW IT WORKS
- Visitors browse services, packages, included items, and prices.
- The language selector switches the website between English, Sinhala, and Tamil.
- There is no checkout, sign-up, or online ordering system.
- Service and package buttons open WhatsApp with a pre-filled message.
- WhatsApp contact is configured for 072 665 8372 (+94 72 665 8372).

ORIGINAL IMAGE QUALITY
When sending finished design files to customers, attach the original file as a Document in WhatsApp instead of sending it as a normal Gallery photo. If the file is too large, upload it to a cloud drive and send a download link with access permissions configured for the customer.

PRICE NOTE
Package prices and inclusions were carried over from the earlier DNET Studio website as a starting point. Please review them before publishing; confirm any offer limits, turnaround times, and revision conditions yourself.

TO OPEN
Double-click OPEN WEBSITE.bat, or open index.html in your browser.
